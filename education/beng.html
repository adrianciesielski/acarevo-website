The Engineering Project

Numerical analysis of biofilm behaviour in a continuous bioreactor.

The project examined the properties and behaviour of biofilm in a continuous stirred-tank bioreactor using the AquaSim simulation environment.

The work focused on building and analysing a numerical representation of the process and investigating how the model responded to selected operating conditions.

The project was completed as part of my studies in chemical and process engineering and introduced me to process modelling and simulation-based analysis.

Project Objectives

Understanding process behaviour through simulation.

01

Define the process system

Represent a continuous stirred-tank bioreactor and the associated biofilm process.

02

Build the simulation model

Implement the process representation using the AquaSim modelling environment.

03

Analyse biofilm behaviour

Examine how the simulated biofilm responded under selected process conditions.

04

Interpret process results

Use the simulation results to describe the behaviour of the investigated system.
